## 機能1：ログイン機能

**ユーザーストーリー**

自分と同居人がそれぞれ別のユーザーとして、感想を登録したい。
なぜなら、別ユーザーとして扱わないと登録した情報が混ざってしまうため。

**受け入れ条件（これができたら完成）**

- [ ] ユーザー名、メールアドレス、パスワードでユーザー登録ができる
- [ ] 同じメールアドレスで登録できない
- [ ] 登録したメールアドレス、パスワードでログインができる
- [ ] メールアドレス、パスワードが登録したものと異なるとログインができない
- [ ] ログアウトすることでログイン前の状態にすることができる

## 機能2：服装のオススメ 機能

**ユーザーストーリー**

その日の体感温度とユーザーごとの以前の感想をもとに、オススメの服を表示したい。
なぜなら、予報アプリの気温と体感温度や、服装指数と自分の感じ方が異なることがあるため。

**受け入れ条件（これができたら完成）**

- [ ] ログインした人に体感温度から基準をもとにオススメの服を表示する
- [ ] ログインしていない人はオススメを見ることができない
- [ ] オススメする服は7時の現在地の体感温度で決める
- [ ] 感想が登録されていた場合はそれ反映したものをオススメする
- [ ] 直近1週間の感想が「寒かった」2回・「暑かった」1回なら、体感温度を1℃低いものとして提案する
- [ ] 感想が「家を出ていない」場合、その日の感想は反映されない
- [ ] 朝、昼、夜で17℃の場合、薄手ジャケットを提案する
- [ ] 朝、昼が17℃で夜が15℃の場合、薄手ジャケットを提案し、夜は冷えるのでもう1枚厚い上着を提案する
- [ ] 朝17℃、昼が20℃、夜が15℃の場合、薄手ジャケットを提案し、昼は暖かいので脱ぎやすい服、夜は冷えるのでもう1枚厚い上着を提案する
- [ ] 朝が16℃で昼と夜も変わらないが、直近の感想で「寒かった」が1回あった場合は、裏地付トレンチコートを提案する

## 機能3：感想の登録機能

**ユーザーストーリー**

ユーザーごとにおすすめされた服装の感想を登録したい。
なぜなら、人によって感じる暑さが異なるため。

**受け入れ条件（これができたら完成）**

- [ ] ログインした人はオススメされた服の感想を「暑かった / ちょうどよかった / 寒かった / 家を出ていない」から選んで登録できる。
- [ ] 感想を登録できるのは1日に1回だけ
- [ ] 過去の日の感想は後から登録できない（未登録の日は、一覧に「感想なし」と表示する）
- [ ] 直近1週間の感想は、一覧から編集できる
- [ ] 他のユーザーの感想は編集できない
- [ ] ログインしていない人は感想を登録できない

## 機能4：小物のオススメ機能

**ユーザーストーリー**

その日の天気をもとに傘を持っていくかどうかを知りたい。
なぜなら、夕方から雨などに気づけず傘を忘れたことがあるため。

**受け入れ条件（これができたら完成）**

- [ ] 現在地の降水確率が40%以上の場合は雨と判断する
- [ ] 午前（7〜12時）と午後（13〜19時）の両方に40%以上の時間があるなら傘、午前と午後のどちらかだけなら折り畳み傘を提案する
- [ ] 7〜19時の間で最大の降水確率と時間を表示する
- [ ] 降水確率が7〜16時は20%、17時に60%、18〜19時は30%の日は、「折り畳み傘」をすすめ、「最大降水確率60%（17時）」と表示する
- [ ] 降水確率が7〜19時が40%未満の場合、傘をすすめず、「最大降水確率30%（17時）」と表示する

## やらないことリスト

- 持っている服の登録(感想の反映を優先)
- よく行く場所(感想の反映を優先)
- 雪(自分の住んでいる地域で雪がほぼ降らない)
- 時間帯を自分で変えること(決められた時間で正しい挙動をさせることを優先)
